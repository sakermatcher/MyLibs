sak.math (English Documentation)
================================

Overview
--------
`sak.math` is a lightweight numeric and plotting helper library built on top of `decimal`, `pandas`, `matplotlib`, and `seaborn`. It provides:

* A precise `vector` class (internally stores `Decimal` values) with arithmetic, slicing, and utility operations.
* Data import via `load` (aliases: `imp`, `cargar`) for CSV / XLSX / JSON with direct conversion of columns to vectors.
* Expression based functions (`fx`) and polynomial regression (`polyfit`).
* Quick plotting primitives: line, scatter, bar, box, pie, heat map, and multi–subplot figures.
* Spanish aliases exposed in `esp` and a few bilingual synonyms inside `eng` (e.g. `mostrar`).

Installation
------------

```powershell
pip install matplotlib seaborn pandas
```

Import Flavors
--------------
Use English API:

```python
import sak.math.eng as sak
```

Or Spanish API:

```python
import sak.math.esp as sak
```

Quick Start
-----------
```python
import sak.math.esp as sak  # or eng

# Import spreadsheet and extract columns B and C (rows 6..83 inclusive)
data = sak.imp("tests", type="xlsx")
t = data.toVec("B", 6, 83)
x = data.toVec("C", 6, 83)

# Polynomial fit (degree 2) and evaluate
pol = sak.polyfit(t, x, 2)
y = pol.calc(t)

# Plot original vs fitted curve
p = sak.plotLine(t, x, title="Test Plot", x_label="T values", y_label="X values", color="green")
p.addData(t, y, label="Fitted")
p.show()
```

Core Concepts
-------------
### Precision & Decimal
All numeric values inside `vector` and generated by `fx` / `polyfit` are stored as `Decimal` to reduce floating point drift. When plotting, values are converted to Python floats.

### Vectors
Create ranges or from raw data:
```python
v1 = sak.vec(10)            # 0..10 inclusive, step 1
v2 = sak.vec(2, 5)          # 2..5 inclusive
v3 = sak.vec(0, 11, 0.1)    # 0..11 inclusive step 0.1
v4 = sak.vec(data=[3, 6, 9])
```
Arithmetic pairs elementwise (lengths must match):
```python
v_sum = v1 + 2
v_mix = v2 + v4            # raises if lengths differ
diffs = v3.diff()
total = v4.sum()
idx = v4.find(6)           # returns index or None
```
Slice returns a new vector: `v_part = v3[10:20]`.

### Linspace
Create a vector with a specified number of evenly spaced points between start and stop (inclusive):
```python
v_lin = sak.linspace(0, 10, 5)  # 0, 2.5, 5, 7.5, 10
```

### Data Import (`load` / `imp`)
```python
dataset = sak.imp("mydata", type="csv")
colA = dataset.toVec("A", 2, 40)        # Excel style column letters
colByIdx = dataset.toVec(1, 2, 40)      # zero-based column index
```
Column letters are translated (A, B, ..., Z, AA, AB...). You can also use exact header names (case-insensitive). Stops when encountering a blank/NaN or the `stop` row.

### Data Save (`save` / `exp`)
```python
dataset.save("outputFile", vec1, vec2, names=["Time","Value"])
```
Saves vectors to `outputFile.xlsx`, names: optional list of column headers.

### Functions (`fx`)
Build from a string expression. Supported operators: `+ - * / ^` and trig (`sin`, `cos`, `tan`), `log`, `sqrt`, constants `e`, `pi`. Trig can be in degrees (default) or radians.
```python
f = sak.fx("-0.2x^2 + 2.4x + 22.8")
g = sak.fx("sin(x) + 3", degRad="rad")
val = f.calc(4)
y_vals = f.calc(v3)          # returns vector
```
You can pass named constants: `f.calc(v3, A=2, B=5)` if your equation uses `A`, `B`.

### Polynomial Fit (`polyfit`)
Least squares polynomial regression returning an `fx` instance.
```python
poly = sak.polyfit(t, x, 2)
pred = poly.calc(t)
```
Raises if lengths differ or degree < 0, or if system is singular (rare: identical x points with conflicting constraints).

Plotting
--------
Color cycles automatically. Each plot object has `.show(block=True)` and Spanish alias `.mostrar`.

### Line / Scatter (`plotLine`)
```python
p = sak.plotLine(t, x, title="Sample", x_label="Time", y_label="Value", type='l')
p.addData(t, y, label="Fit", type='l')
p.show()
```
Parameters:
* `x`, `y`: vectors
* `type`: 'l' (line) or 's' (scatter)
* `pointTypes`: marker when scatter
* `addData(...)` adds additional series

### Heat Map (`plotHeatMap`)
```python
hm = sak.plotHeatMap(values=[[1,2],[3,4]], x_labels=["A","B"], y_labels=["R1","R2"], title="Heat")
hm.show()
```
`showVals=True` annotates cells; `cmap` any matplotlib colormap string.

### Box Plot (`plotBox`)
```python
bp = sak.plotBox(sak.vec(data=[5,7,8,6,9]), title="Distribution")
bp.show()
```

### Bar Plot (`plotBar`)
```python
bars = sak.plotBar(["A","B","C"], sak.vec(data=[10,5,7]), title="Counts")
bars.show()
```

### Pie Chart (`plotPie`)
```python
pie = sak.plotPie(["Cat A","Cat B"], sak.vec(data=[60, 40]), title="Share")
pie.show()
```

### Multi–subplot Figures (`fig` / `figure`)
Arrange plot objects in a 2D grid:
```python
fig = sak.figure([
	[hm, p],
	[bp, pie]
])
fig.show()
```

API Reference
-------------
### vector
Constructor forms:
* `vec(stop)` → range 0..stop
* `vec(start, stop)` → step 1
* `vec(start, stop, step)`
* `vec(data=[...])` provide explicit elements
* `linspace(start, stop, numPoints)` → vector with `numPoints` evenly spaced points between `start` and `stop` (inclusive).

Key methods: `sum()`, `diff()`, `find(value)`, `addData(list)`, `append(val)`, `combine(other)`, `toFloats()`, slicing `v[a:b]`.
Operators: `+ - * /` with scalar or equal-length vector.

### load / imp
`load(filepath: str, type: 'csv'|'xlsx'|'json')` – reads `filepath.<type>`.
`toVec(col, row=1, stop=None)` – column extraction; `col` may be int, header name, or letters.

### save / exp
`save(filepath: str, *vectors: vector, names: list[str]=None)` – saves vectors to `filepath.xlsx`, `names`: optional list of column headers.

### fx
`fx(equation: str, degRad='deg')` – builds expression. Use `calc(x)` or alias `eval(x)` where `x` is scalar or vector.
Constants/trig auto–wrapped in `radians()` when `degRad='deg'`.

### polyfit
`polyfit(x: vector, y: vector, degree: int) -> fx` – least squares polynomial (returns an `fx`).

### plotLine
`plotLine(x: vector, y: vector, x_label='X-axis', y_label='Y-axis', title='Plot', label='', color=None, type='l', pointTypes='', showGrid=True)`
Add series: `addData(x, y, label='', color=None, type='l', pointTypes='')`.

### plotHeatMap
`plotHeatMap(values, x_labels=None, y_labels=None, title='Heat Map', showVals=True, cmap='viridis', showGrid=True)`.

### plotBox
`plotBox(values: vector, x_label='X-axis', y_label='Y-axis', title='Box Plot', color=None, showGrid=True)`.

### plotBar
`plotBar(names: list[str], y: vector, x_label='', y_label='', title='Bar Plot', color=None, showGrid=True)`.

### plotPie
`plotPie(names: list[str], values: vector, title='Pie Chart', colors=None)`.

### fig / figure
`fig(subPlots: list[list])` – 2D arrangement; any inner list is a row. `.show()` renders all.

Aliases & Internationalization
------------------------------
Spanish equivalents available (examples): `imp`/`cargar`, `mostrar`, `graficaLinea`, `graficaMapaCalor`, `graficaCaja`, `graficaBarras`, `graficaPastel`, `figura`.

Error Handling & Edge Cases
---------------------------
* `vector(step=0)` raises `ValueError`.
* Length mismatch in vector arithmetic or `polyfit` raises `ValueError`.
* Singular matrix during `polyfit` raises `ValueError("Matrix is singular...")`.
* `load` with unsupported `type` raises `ValueError`.
* `toVec` stops at first NaN or when `stop` exceeded.
* `fx.calc` raises if `x` is not scalar or `vector`.

Performance Notes
-----------------
`polyfit` uses naive Gaussian elimination (O(n^3) in degree). Suitable for small polynomial degrees (typical <= 6). For large datasets or degrees consider integrating NumPy.

Full Example (Combined)
-----------------------
```python
import sak.math.esp as sak

data = sak.imp("tests", type="xlsx")
t = data.toVec("B", 6, 83)
x = data.toVec("C", 6, 83)
pol = sak.polyfit(t, x, 2)
y = pol.calc(t)

p_line = sak.plotLine(t, x, title="Data vs Fit", x_label="t", y_label="x")
p_line.addData(t, y, label="Quadratic Fit")

hm = sak.plotHeatMap(values=[[1,2,3],[3,2,1],[2,3,4]], x_labels=["A","B","C"], y_labels=["R1","R2","R3"], title="Pattern")
box = sak.plotBox(sak.vec(data=[5,7,8,6,9,5]), title="Dispersion")
pie = sak.plotPie(["Cat A","Cat B","Cat C"], sak.vec(data=[15,30,55]))

fig = sak.figure([
	[hm, p_line],
	[box, pie]
])
fig.show()
```
